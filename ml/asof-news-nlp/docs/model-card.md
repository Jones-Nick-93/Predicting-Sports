# Model card

## Intended use
Portfolio demonstration of text classification, calibration, bitemporal features, and leakage auditing.
## Models
TF-IDF unigram/bigram features, logistic classifier, and held-out logistic Platt calibrator.
## Limitations
Generated language is small and deliberately separable; complete feedback and clean entities are unrealistic; calibration is sample-sensitive; no real-domain validity is claimed.
## Promotion
No model is promoted. Real use requires licensed point-in-time text, revision lineage, entity resolution, missingness policy, drift monitoring, and repeated walk-forward validation.
