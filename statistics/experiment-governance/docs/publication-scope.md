# Publication Scope

This repository is limited to generic experiment-governance and inference mechanics.
All examples and tests use fabricated values.

The public project excludes:

- forecasting models, features, signals, and data-source details;
- real predictions, positions, prices, results, or performance history;
- Kelly ladders, bankroll caps, correlated-exposure limits, and staking rules;
- live-promotion thresholds and execution gates;
- private agent, ensemble, voting, or production-system architecture;
- credentials, endpoints, licensed data, and serialized model state.
