# Publication Scope

This repository may publish the generator, evaluation harness, model adapters,
synthetic fixtures, aggregate synthetic results, tests, and documented negative
results.

It must not contain credentials, private paths, hostnames, licensed feeds, real
fixtures, live forecasts, posted prices, wagers, account metadata, bankrolls,
private feature definitions, fitted private parameters, selection logic, or
claims of real-world profitability.

The demo is methodological career evidence only. It does not grant production or
wagering authority.
