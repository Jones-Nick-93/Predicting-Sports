# Public Repository Rules

- Keep every schema, table, column, key, status, and searched value fictional.
- Never add real query results, screenshots, plans, server names, database names,
  customer identifiers, vendor schemas, or production-derived field interpretations.
- Preserve read-only behavior and parameterize searched values.
- Wrap dynamic identifiers with `QUOTENAME` and document query-cost risks.
- Treat overlap and profiling as discovery evidence, not verified business semantics.
- Before publication, scan both files and Git history and preserve the MIT license notice.
