# Publication scope

This entire project is intended for public portfolio use.

Allowed:

- Generic mathematical methods.
- Generated probabilities and odds.
- Property-based and deterministic tests.
- Reproducible negative results and documented limitations.

Forbidden:

- Real prices, events, projections, wagers, accounts, bankroll values, or CLV.
- Vendor data, credentials, endpoints, or licensed feeds.
- Private features, parameters, selection rules, or system architecture.
- Claims of profitability or real-world predictive superiority.
